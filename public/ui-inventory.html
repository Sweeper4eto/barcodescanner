8. Къде какво се случва (кратко)

Логин → /app (hub или classic). What's new + billing reminder (ако трябва).

Годност → списък / sheet / към количка / скан / документ (табове).

Скан / Добави → нов inventory entry в текущия обект.

Количка → buy-list; може обратно към годност.

Документ → OCR → draft → location confirm → импорт в годност.

Екип → хора/права; Activity → revert; График → смени.

Плащания → статус; Pay → метод; lock gate при просрочие.

Известия → push правила; Поддръжка → ticket в admin.

Хедър → лого=Начало; стрелка=назад; флаг=език; chip=обект.

Admin → акаунти, плащания, support, what's new push, OCR usage…
